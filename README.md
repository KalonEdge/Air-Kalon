## How it works

One device shows the file as a stream of moving codes on its screen. The other reads them with its camera and rebuilds the file. Nothing travels over Wi-Fi, Bluetooth or a cable, and there is nothing to pair. The receiver can start at any moment and doesn't need to catch every frame, and every file is checked before it's offered to you.

## Requirements

macOS 14 Sonoma or later, on a Mac with Apple silicon. Receiving uses your Mac's camera.

## Install

1. Download [Air-Kalon.dmg](https://github.com/KalonEdge/Air-Kalon/releases/latest/download/Air-Kalon.dmg).
2. Open it and drag Air Kalon into Applications.
3. Open Air Kalon from your Applications folder. The first time you receive, macOS asks for permission to use the camera.

Air Kalon is signed by its developer and notarized by Apple.

## Updates

Air Kalon keeps itself up to date. It checks for a new version twice a day, downloads it in the background and installs it when you quit, so it never interrupts a transfer. To check right away, choose Air Kalon › Check for Updates…. Automatic updates can be turned off in the Software Update window.

Every version is listed, with what changed, on the [Releases](https://github.com/KalonEdge/Air-Kalon/releases) page.

## Privacy

Transfers use no network at all: no internet, no Wi-Fi, no Bluetooth and no account. Checking for updates is the only time Air Kalon connects to the internet, and it sends only the version of Air Kalon you have. The camera is on only while you're receiving, or while Auto-stop watches for the receiver's confirmation, and what it sees stays on your Mac and is never saved. A file you receive stays in memory until you choose where to save it.

Transfers are not encrypted. Anyone who can see or film the sending screen can capture the file, so send private files where nobody else can see the screen. Read more at [kalonedge.com/privacy](https://kalonedge.com/privacy/).
