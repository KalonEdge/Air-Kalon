# Security

If you believe you've found a security issue in Air Kalon, please report it privately rather than in public, using the contact form at [kalonedge.com/contact](https://kalonedge.com/contact/).

Please include the version of Air Kalon (Air Kalon › About Air Kalon), your version of macOS, and the steps that show the issue.

## Supported versions

Security fixes go into the latest release. Air Kalon installs updates by itself, so keeping Update automatically on (Air Kalon › Check for Updates…) keeps you protected.
